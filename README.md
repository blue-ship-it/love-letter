# A letter for Hrishit

A small, typewritten love-letter site inspired by the reference you shared. It is intentionally dependency-light and ready for Vercel, Netlify, or GitHub Pages.

## Add your song

1. Put an MP3 you have permission to use at `public/song.mp3` (create the `public` folder if it does not exist).
2. Update `title` and `artist` near the top of `src/main.js`.
3. Run `npm install`, then `npm run dev` to preview it. `npm run build` creates the deployable production version.

The letter and its typewriter effect already contain Dishi's message to Hrishit. To edit it later, change the `letter` list in `src/main.js`.

## Deploy to Vercel

Import this repository at [vercel.com/new](https://vercel.com/new), keep the default Vite settings, and select **Deploy**. No environment variables are needed.

## Privacy

This project contains a personal letter. Keep the repository private unless you deliberately want the source readable by anyone.
